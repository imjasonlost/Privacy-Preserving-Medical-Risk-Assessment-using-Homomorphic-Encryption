# Privacy-Preserving-Medical-Risk-Assessment-using-Homomorphic-Encryption
This repository contains preliminary code to calculate the risk score of the Khorana Test and Diabetes Test (based on HbA1c values) using Homomorphic encryption. 
A paper based on this code is accepted at the IEEE Secure Development Conference 2025, @Purdue University in Indianapolis. 
Polynomial approximation is used to compare real values in homomorphic encryption using Chebyshev polynomials. 
1) Data directory contains the OriginalData link and synthetic diabetes dataset
2) The doc_FHE_setup directory contains pdf file that explains how to install the OpenFHE library in PC
3) The src directory contains all the necessary codes 
4) The results directory contains some of the plots as results.

Paper Link: https://www.researchgate.net/publication/397594312_Privacy-Preserving_Medical_Risk_Assessment_Using_Homomorphic_Encryption
